Integrasi Google Drive

1. Buka Google Drive > Buat Folder Baru > Salin ID Folder-nya dari URL.
2. Kunjungi script.google.com > Buat Proyek Baru.
3. Paste kode di bawah ini, masukkan ID Folder di baris pertama.
4. Klik Deploy > New Deployment > Pilih type Web app.
5. Set Execute as: Me dan Who has access: Anyone.
6. Salin Web app URL yang dihasilkan dan masukkan ke kolom di atas.
